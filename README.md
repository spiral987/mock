# mock

レイヤー・フォルダ・クリッピングに対応した、ブラウザで動くペイントアプリ。

## 機能

- ブラシ / Gペン / 鉛筆 / エアブラシ / 消しゴム / 塗りつぶし / 投げ縄塗り / スポイト / 直線 / 矩形
- 投げ縄選択、Transform（移動・拡大縮小・回転）、明度・色相調整
- レイヤー・フォルダ（グループ）・クリッピングマスク・不透明度・表示切替・乗算・並べ替え（D&D）
- 差分スロットと状態・所属の管理
- 画像 / PSD インポート、PNG 書き出し
- 非破壊のキャンバスサイズ変更、Undo/Redo、ズーム / パン（視点移動）

描画処理は `src/engine`、編集状態と Undo/Redo は `src/session.ts`、画面は `src/frontend` にあります。
編集処理はブラウザ内で動作します。Undo/Redo のための操作記録は内部で保持します。

## 開発

```sh
npm install
npm run dev        # 開発サーバ
npm run build      # 型チェック + 本番ビルド
npm run typecheck  # 型チェックのみ
```
